# Gardenia - Floricultura Online

O **Gardenia** é um sistema de simulação de vendas online desenvolvido para unificar a experiência de **clientes e funcionários** em uma única plataforma.

O projeto combina uma interface moderna e intuitiva para usuários finais com uma área administrativa funcional para gestão de pedidos e produtos.

---

## Sobre o Projeto

O Gardenia foi criado com o objetivo de oferecer uma experiência completa de compra de flores online, permitindo que clientes personalizem seus pedidos enquanto funcionários gerenciam todo o fluxo da loja.

A proposta é unir **design, usabilidade e funcionalidade**, simulando um ambiente real de e-commerce.

---

## Área do Cliente

O sistema oferece aos clientes uma experiência completa e interativa:

-  Acesso ao perfil do usuário  
-  Gerenciamento de endereços cadastrados  
-  Cadastro de formas de pagamento  
-  Visualização de buquês prontos   
-  Montagem de buquê personalizado com carrossel interativo  
-  Carrinho de compras com controle de quantidade  
-  Simulação de finalização de compra  
-  Histórico de pedidos e status

---

## Área do Funcionário

A área administrativa foi projetada com foco em eficiência:

-  Cadastro e gerenciamento de produtos  
-  Visualização de pedidos realizados  
-  Confirmação de pagamentos  
-  Gerenciamento de perfil  
-  Controle geral do sistema  

---

## Funcionalidades Gerais

-  Sistema completo com áreas separadas (cliente e funcionário)  
-  Simulação de e-commerce  
-  Navegação simples e intuitiva  
-  Organização e gerenciamento de dados
